# כתר מלך-הצללים — ספר-משחק לטרמינל

משחק "בחר את ההרפתקה שלך" בסגנון ספרי Fighting Fantasy, בעולם פנטזיה קלאסי.
כל דף מספר קטע סיפור ומציע בחירות; יש קוביות, קרבות, ציוד, חנות, ושמירת משחק.

## הורדה ל-Windows (בלי Python)
1. בגיטהאב, בעמוד **Releases** של הריפו, פותחים את הגרסה האחרונה בשם "Shadow Crown gamebook for Windows".
2. מורידים את `ShadowCrown.exe` ומריצים בלחיצה כפולה.
3. אם Windows מזהיר שהקובץ לא מוכר (כי הוא לא חתום): לוחצים "More info" ואז "Run anyway".

השמירות וההגדרות נשמרות בתיקייה שבה נמצא ה-EXE, אז כדאי לשים אותו בתיקייה משלו.
ה-EXE נבנה אוטומטית ב-GitHub Actions (`.github/workflows/gamebook-windows-exe.yml`) בכל שינוי במשחק.

## הרצה מהקוד
```
cd gamebook
python main.py
```
צריך Python 3.7 ומעלה, בלי ספריות נוספות.

### עברית ב-CMD
ה-CMD של Windows לא כותב מימין לשמאל. בהפעלה הראשונה המשחק מציג שתי שורות
ושואל איזו מהן נקראת נכון, ושומר את הבחירה (אפשר לשנות בתפריט > "כיול תצוגת עברית").
- אפשר גם לכפות מצב: `python main.py --rtl` (היפוך עצמי) או `--no-rtl`.
- מומלץ Windows Terminal עם גופן כמו Consolas או Courier New.
- אפשר להתקין `pip install python-bidi` לתצוגה מדויקת יותר. המשחק ישתמש בה אוטומטית.

## חוקים
- **תכונות** (מוגרלות בקוביות): כוח, זריזות, מזל, חיים. מקצוע: לוחם / גנב / קוסם.
- **קרב**: בכל סבב אתה מטיל 2d6 + כוח + בונוס נשק, והאויב מטיל 2d6 + כוח שלו. מי שגבוה יותר פוגע.
  שריון מפחית את הנזק שאתה סופג. גנב נלחם בזריזות במקום בכוח (אם היא גבוהה יותר).
  קוסם יכול להטיל חץ קסם (2d6+1 נזק, עולה מאנה ותור - האויב מנסה לפגוע בך בזמן ההטלה).
- **בדיקת תכונה**: d20 + תכונה, ואתה צריך להגיע לפחות לדרגת הקושי.
- **בדוק מזל**: 2d6 קטן או שווה למזל שלך = הצלחה. בכל בדיקה המזל יורד ב-1.
- פקודות בכל דף: `i` מלאי, `s` מצב, `p` שתיית שיקוי, `save` שמירה, `q` חזרה לתפריט.

## הוספת דפים והרפתקאות
כל הסיפור נמצא ב-`story/adventure.json`, והקוד לא תלוי בו. דוגמה לדף:
```json
"12": {
  "text": "אתה מגיע לגשר רעוע...",
  "effects": [{"type": "add_item", "item": "חבל"}, {"type": "gold", "amount": 5}],
  "choices": [
    {"text": "חצה בזהירות", "check": {"stat": "agility", "dc": 15, "success": "14", "fail": "13"}},
    {"text": "קשור את החבל", "requires": {"item": "חבל"}, "goto": "15"},
    {"text": "קפוץ (בדוק מזל)", "luck": {"success": "15", "fail": "17"}}
  ]
}
```
- **effects**: `add_item`, `remove_item`, `gold`, `heal`, `damage` (מספר או "1d6+1"), `stat`, `mana`, `set_flag`, `message`
- **requires**: `item`, `no_item`, `flag`, `no_flag`, `class` (warrior/thief/mage), `gold`, `mana`
- **combat**: `{"name", "skill", "hp", "damage"?, "win", "flee"?}` או `{"enemies": [...], "win": ...}`
- **shop**: `[{"item": "שיקוי ריפוי", "price": 5}]`
- **ending**: `"win"`, `"true"` (הסוף האמיתי), `"alt"` (סוף אחר), `"bad"` או `"death"`

אחרי עריכה הריצו `python validate.py` כדי לבדוק שאין קישורים שבורים או דפים שאי אפשר להגיע אליהם,
ו-`python balance.py` כדי לראות אחוזי ניצחון ומוות לכל מקצוע ולחפש לולאות שאפשר לנצל.

## סוכנים לכתיבת הסיפור
בתיקייה `.claude/agents/` יש שלושה סוכנים של Claude Code:
- **story-writer**: כותב דפים, מסלולים וסופים חדשים
- **story-improver**: עורך את הטקסט, שומר על רצף, ומתקן ממצאים של הבודק
- **story-auditor**: מחפש רמאויות ובעיות מכניקה וכותב דוח ל-`AUDIT.md`

כמה סוכנים יכולים לכתוב במקביל: כל אחד כותב קובץ חלק ל-`story/parts/` (דפים חדשים + hooks לדפים קיימים),
ו-`python merge_parts.py` ממזג אותם לסיפור.
