# נגן השכבות

נגן למוזיקת בוס שלא נגמרת. כל שלב מתנגן בלופ כל עוד הסצנה נמשכת, וה‑DM מחליף שלב, עוצמה וסיום בלחיצה. המעבר בין שלבים קורה תמיד בתחילת התיבה הבאה.

## הפעלה

אפשר לפתוח את הנגן בכל דפדפן:

```bash
cd rost1234 && python3 -m http.server 8000
# ופותחים: http://localhost:8000/player/
```

צריך שרת, כי דפדפן לא טוען קבצים ישירות מהדיסק. כל סט שמופיע ב‑`player/sets.json` מופיע בנגן.

## מה יש בעמוד

- **שלבים:** לחיצה על שלב מעבירה אליו בתחילת התיבה הבאה. אם לשלב יש קטע מעבר (rise) והתיבה "להיכנס דרך המעבר" מסומנת, המעבר מתנגן מעל הלופ הישן, והשלב החדש מתחיל בדיוק כשהמעבר נוחת.
- **עוצמת הקרב:**
  - **רגוע:** מצע בלבד.
  - **מתח:** מצע וקצב.
  - **מלא:** כל השכבות.

  השכבות נכנסות ויוצאות בהדרגה, בלי לעצור את המוזיקה.
- **סיומים:** הסיום מתנגן בתחילת התיבה הבאה, והלופ נעצר.
- **מקלדת:**
  - רווח: נגן או עצור.
  - 1 עד 9: מעבר לשלב.
  - Q, W, E: רגוע, מתח, מלא.

## הקבצים

| קובץ | מה הוא |
|---|---|
| `layered-player.js` | המנוע. JavaScript בלי תלויות ובלי בנייה, שמשתמש ב‑Web Audio. אותו קובץ רץ גם בשולחן של גיא. |
| `index.html` | עמוד ה‑DM. |
| `sets.json` | רשימת הסטים שהנגן טוען. |
| `export_ccgm.py` | מעתיק סט לתיקיית המוזיקה של הפרויקט של גיא (ראו `integration/ccgm/README.md`). |

## צורת סט

`render_layers.py` (ב‑skill `boss-music`) כותב לכל סט קובץ `manifest.json`, ולידו את קובצי השמע:

- **לכל שלב:** שלוש שכבות, `bed`, `rhythm` ו‑`melody`. כולן באותו אורך ועם אותה נקודת לופ, כך שהן מתנגנות בסנכרון מדויק, ובחיבור שלהן מקבלים את המיקס המלא.
- **פתיחה ולופ:** הפתיחה, `[0, loopStart)`, מתנגנת פעם אחת. אחריה הגוף, `[loopStart, סוף)`, חוזר על עצמו בלי סוף.
- **קטעים חד‑פעמיים (`cues`):** מעבר עם `landsAt`, כלומר מתי השלב הבא מתחיל, ו‑`to`, כלומר לאיזה שלב. וגם סיומים.

**Safari:** הקבצים בפורמט Ogg Vorbis. Chrome, Edge ו‑Firefox מנגנים אותם. ב‑Safari לא בדקתי.
