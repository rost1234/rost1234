# פנייה לעסקים: מאמני כושר וסטודיואים

שני חלקים, שניהם עובדים מהטלפון:

1. **כלי הלידים:** `https://rost1234.github.io/rost1234/`
   מוצא בגוגל מפות מאמני כושר וסטודיואים בעיר שבוחרים, ומסמן את מי שאין לו אתר (או שהקישור שלו מוביל רק לאינסטגרם).
   לכל עסק הוא מכין הודעה אישית ופותח וואטסאפ עם ההודעה מוכנה. אתם רק לוחצים "שלח".
   הכלי עוקב אחרי כל עסק: נשלחה פנייה, מעוניין, קיבל דוגמה, קיבל הצעת מחיר, נסגר.
2. **אתר הדוגמה:** `https://rost1234.github.io/rost1234/demo/fitness/`
   אתר לסטודיו כושר שמופיע **עם השם של העסק**, העיר והדירוג שלו בגוגל. יש עיצוב שונה לפילאטיס, יוגה, קרוספיט, מאמן אישי וסטודיו.
   בעל העסק יכול לנסות "לקבוע אימון ניסיון" ולראות איך הלקוחות שלו יפנו אליו בוואטסאפ, ומשם לכתוב לכם ישר.

## הפעלה (פעם אחת)

1. ממזגים את הקוד ל-`main`.
2. ב-GitHub נכנסים ל-**Settings ← Pages**, ותחת **Source** בוחרים **GitHub Actions**.
3. בלשונית **Actions** מריצים את **Outreach site** (או מחכים לדחיפה הבאה ל-`main`). אחרי דקה-שתיים האתר באוויר.
4. פותחים את הכלי בטלפון ומוסיפים אותו למסך הבית (בכרום: תפריט ← "הוספה למסך הבית").
5. בכלי, במסך **הגדרות**: כותבים שם וטלפון נייד. הם מופיעים בהודעות ובאתר הדוגמה.

## מפתח Google Maps

הכלי מחפש עסקים דרך ה-API הרשמי של גוגל. צריך מפתח, פעם אחת, וזה לוקח בערך 10 דקות.

1. נכנסים ל-[Google Cloud Console](https://console.cloud.google.com/) ויוצרים פרויקט חדש (למשל `leads`).
2. **Billing:** מחברים כרטיס אשראי. גוגל נותנת מכסה חינמית כל חודש. החיפוש בכלי הוא מסוג
   **Text Search Enterprise**, ונכון לעכשיו יש לו **1,000 קריאות בחינם בחודש** ([מחירון](https://developers.google.com/maps/billing-and-pricing/pricing)).
   חיפוש של עיר עם כל 5 סוגי העסקים = 5 קריאות, כלומר בערך 200 ערים בחודש בחינם. הכלי מראה כמה השתמשתם החודש.
3. **APIs & Services ← Library:** מפעילים את **Places API (New)** ואת **Maps JavaScript API**.
4. **APIs & Services ← Credentials ← Create credentials ← API key.**
5. לוחצים על המפתח החדש ומגבילים אותו (חשוב, כדי שאף אחד אחר לא ישתמש בו):
   - **Application restrictions:** בוחרים **Websites** ומוסיפים `https://rost1234.github.io/*`
   - **API restrictions:** בוחרים **Restrict key** ומסמנים רק את שני ה-API מסעיף 3.
6. רשת ביטחון (מומלץ):
   - **Billing ← Budgets & alerts:** מגדירים תקציב של 5$ עם התראה למייל.
   - **Places API (New) ← Quotas:** מגבילים את **Text Search requests per day** ל-50, למשל.
7. מעתיקים את המפתח (מתחיל ב-`AIza`) ומדביקים בכלי, במסך **חיפוש**. המפתח נשמר רק בדפדפן שלכם.

בלי מפתח אפשר להתחיל מיד: **חיפוש ← הוספה ידנית**, עם עסקים שמצאתם בגוגל מפות או באינסטגרם.

## השגרה היומית (15–20 דקות)

- **פעם בשבוע:** חיפוש בעיר חדשה ב-**חיפוש**. הכלי מסמן מראש את העסקים שכדאי לפנות אליהם.
- **כל יום, במסך "היום":**
  - **הפנייה הבאה:** קוראים את ההודעה, משנים מילה אם רוצים, ולוחצים "שליחה בוואטסאפ". הכלי עובר לעסק הבא.
  - **להתקשר היום:** מי שלא ענה 4 ימים מקבל שיחה אחת. התסריט מופיע על המסך.
  - יעד: עד 20 פניות חדשות ביום.
- **כשעונים**, ב-**רשימה**:
  - ענו "כן" ← "ענו: מעוניינים" ← שולחים את הדוגמה האישית שלהם.
  - אחרי שיחה קצרה ← שולחים הצעת מחיר (המחיר נקבע ב**הגדרות**).
  - נסגר ← "נסגר! 🎉" עם הסכום. הסכום נכנס לסיכום ההכנסות במסך "היום".

## הכללים (חשוב)

- **ההודעה הראשונה רק שואלת אם אפשר לשלוח**, בלי קישור. את הדוגמה שולחים רק אחרי שענו "כן".
- **לא ענו?** שיחה אחת אחרי 4 ימים, ואם אין תשובה, סוגרים. **אמרו לא?** לא פונים שוב לעולם. הכלי זוכר את זה ולא יציע אותם שוב.
- **אין שליחה אוטומטית.** הכלי מכין את ההודעה ואתם שולחים, כל הודעה בנפרד.
- **עד 20 שיחות חדשות ביום.** כדאי להשתמש ב-WhatsApp Business עם שם ותמונה אמיתיים, כדי שוואטסאפ לא יחסום את המספר.
- חוק הספאם (חוק התקשורת, סעיף 30א) אוסר לשלוח פרסומות בלי הסכמה, אבל מתיר לפנות פעם אחת לבית עסק כדי לבקש הסכמה.
  לכן ההודעה הראשונה בנויה כבקשה. אני לא עורך דין. אם תגדלו לנפח גדול, כדאי להתייעץ עם אחד.

## כשמישהו אומר "כן, בוא נעשה את זה"

1. **שיחה של 10 דקות:** מה חשוב להם באתר, איך לקוחות מגיעים אליהם היום, ומה הכי מעצבן אותם.
2. **מה לבקש מהם:** לוגו, 6–10 תמונות (אפשר מהאינסטגרם), מחירים, לוח שעות, כתובת, קישור לאינסטגרם ומספר וואטסאפ.
3. **דומיין** (כתובת כמו `studio-noa.co.il`): בערך 70–100 ₪ לשנה, נרשם על השם של בעל העסק והוא משלם עליו.
4. **תשלום:** חצי לפני שמתחילים, חצי במסירה (ביט או העברה). כדי לתת קבלה צריך לפתוח **עוסק פטור**.
5. **בניית האתר האמיתי:** חוזרים ל-Claude Code עם הפרטים, למשל: "תבנה אתר אמיתי לסטודיו פילאטיס נועה לפי הדוגמה, הנה התמונות והמחירים".

## מה יש בתיקייה

```
outreach/
  site/                 ← מה שעולה לאוויר (GitHub Pages)
    index.html, app.js, style.css   הכלי
    lib.js              הלוגיקה: טלפונים, הודעות, קישורי דוגמה, תור, גיבוי (נבדקת בטסטים)
    dom.js              עזרים קטנים ל-HTML ולאייקונים
    demo/fitness/       אתר הדוגמה: content.js (טקסטים לכל סוג עסק), demo.js, demo.css, og.png (תמונה לתצוגה בוואטסאפ)
  test/lib.test.mjs     טסטים: cd outreach && npm test
```

**פרטיות:** כל הנתונים (העסקים, ההערות והמפתח) נשמרים רק בדפדפן שבו משתמשים בכלי. אין שרת.
כדאי לייצא גיבוי פעם בשבוע (**הגדרות ← ייצוא גיבוי**). המפתח של גוגל לא נכלל בגיבוי.
